# A팀 — SmolVLM-256M-Instruct

## 목표

10/30까지 **SmolVLM-256M에서 "비트 수 → 전이율" 선 하나**를 만든다. 비전 인코더를 8·6·5·4·3비트(+ bnb 8·4)로 양자화한 모델에, 원본 모델로 만든 공격 사진 30장이 몇 % 살아남는지. 예비 실험(3장)에서는 8비트 유지, 4비트 무력화였다. 30장에서도 그런지, 문턱이 어디인지가 이번 결과다.

## 미리 확인해 둔 것

- 프로세서는 `do_image_splitting=False, size={"longest_edge": 512}`. size를 안 주면 기본값 2048이 512 사진을 키웠다 줄여 픽셀이 바뀐다(평균 1.3/255, 최대 24/255).
- 이미지 토큰 64, 입력 76토큰. 종료 토큰 49279. Linear 수 V 72 / C 1 / L 210 / H 1.
- `quant_rtn.apply_rtn`으로 V를 4비트로 하면 가중치 변화 9.38% (예비 실험 nf4 9.42%와 같은 크기).

## 참고_예비실험/

사진 3장으로 한 예비 실험 노트북 1~6과 분석 PDF. **참고용**이고 그대로 돌리는 것이 아니다. 2번 노트북(모델 올리기, bnb 설정, census, 답 길이 재기)은 3단계 코드의 출발점으로 쓸 만하고, 6번(원인 분석 측정)은 최종 발표 때 다시 쓴다. 1번의 공격 코드는 `이미지생성/`으로 옮겼다.
