## 모델 정보 (0단계에서 실제 값으로 확인)

- 사진 512×512, 조각내기 끔, 프로세서 `size={"longest_edge": 512}` → 이미지 토큰 64, 입력 76토큰
- Linear 수: 비전 인코더 72 / 연결부 1 / 언어모델 210 / 출력층 1
- 종료 토큰 49279 (`<end_of_utterance>`). `tie_word_embeddings` False
- 부품 이름: `settings.MODEL_SPECIFIC["smolvlm"]["parts"]`

## 할 일 (공통규칙/진행단계.md 순서)

1. **0단계.** 전처리 일치, census, 재현성. 예비 실험 노트북 2번의 `census`는 `공통규칙/quant_rtn.py`의 것으로 바꾼다.
2. **1단계.** `공통규칙/image_list.csv` 48장 → `data/clean`, `data/noise`. ref로 clean 43장 돌려 상한에 닿는 id 골라내고 `eval_v1.txt` 확정(10/14).
3. **2단계.** `이미지생성/README.md` 4절 TODO 1~7을 먼저 반영하고, 30장 생성 → 저장본 확인 → 해시 → PR. B팀은 이 PR 뒤의 파일을 복사한다.
4. **3단계.** 예비 실험 노트북 2번을 바탕으로: CASES = `settings.PRESETS["phase1"]`, rtn은 `apply_rtn`, bnb는 기존 방식, 생성은 `settings.GEN_KWARGS`, 90개 무작위 순서, 결과 열은 `공통규칙/결과형식.md`. 끝나면 `phase1-extra`.
5. **4단계.** 분석 담당과 함께 그림 2·3·4.
6. **5단계(최종용).** 노트북 6번의 측정을 V 비트별 × 30장으로.
