# 원본 모델에서 성공한 Adversarial Attack, 압축 모델에도 전이되는가

온디바이스 AI 7조 팀 프로젝트 저장소. 사람 눈에 보이지 않는 노이즈로 VLM이 답을 끝내지 못하게 만드는 공격(Verbose Images, ICLR 2024)을 **원본 모델로 만든 뒤**, 같은 모델을 **양자화한 버전**에 넣었을 때도 통하는지를 잰다. 결론은 교수님 요구대로 **수치**(몇 비트에서 공격이 몇 % 살아남는가)와 **trade-off**(공격이 약해지는 만큼 정상 답은 얼마나 나빠지고 용량은 얼마나 줄었는가)로 낸다.

## 두 팀

| 팀 | 모델 | 사진 크기 | 1차 실험 |
|---|---|---|---|
| A | SmolVLM-256M-Instruct | 512×512 (조각내기 끔) | 비전 인코더 고정, 비트 8·6·5·4·3 |
| B | Qwen2-VL-2B-Instruct | 448×448 | 비전 인코더 고정, 비트 8·6·5·4·3 |

두 팀은 **같은 사진 목록, 같은 질문, 같은 생성 설정, 같은 노이즈 상한, 같은 결과 파일 형식**을 쓴다. 공통 값은 [common/settings.py](common/settings.py) 한 곳에만 있고, 규칙은 [docs/02_공통규칙.md](docs/02_공통규칙.md)에 있다.

## 지금 상태와 다음 마감

- 예비 실험(사진 3장, SmolVLM): 8비트는 네 부품 어디를 양자화해도 공격 유지, 4비트는 비전 인코더만 양자화했을 때 공격 무력화. 분석은 [reports/예비실험/](reports/예비실험/).
- **10/30(금) 중간고사 대체 발표: 7분 + 질의 3분, 7분 초과 시 바로 정지.** 그때까지 두 모델의 1차 실험(사진 30장) 결과가 있어야 한다. 주차별 계획은 docs/06.

## 꼭 지킬 것 다섯 가지

1. 공식 실험은 `common/settings.py`의 값으로만 한다. 바꾸고 싶으면 두 팀 합의 → 버전 올림 → 문서 수정.
2. 공격 사진은 원본 모델로 **한 번만** 만들고 고정한다. 평가용 사진으로 공격 설정을 조정하지 않는다.
3. 결과 CSV는 스크립트가 쓴 그대로 올린다. 실행마다 설정 버전·환경·양자화 확인 결과가 같이 기록돼야 한다.
4. 사진 저장은 무손실 PNG만. JPEG는 공격 노이즈를 지운다.
5. 공격 사진은 우리 기기와 우리가 띄운 모델에만 넣는다. 외부 서비스에 올리거나 남에게 보내지 않는다.
