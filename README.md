# 원본 모델에서 성공한 Adversarial Attack, 압축 모델에도 전이되는가

온디바이스 AI 7조.

사람 눈에 안 보이는 노이즈를 사진에 넣어 VLM이 답을 끝내지 못하게 만드는 공격이 있다. 이 공격 사진을 **원본 모델**로 만든 뒤, 같은 모델을 **양자화한 버전**에 넣어도 통하는지를 잰다. 결론은 숫자(몇 비트에서 공격이 몇 % 살아남는가)와 trade-off(그만큼 정상 답은 얼마나 나빠지고 용량은 얼마나 줄었는가)로 낸다.

**10/30(금) 중간고사 대체 발표. 7분 + 질의 3분, 7분 넘기면 바로 정지.** 그때까지 두 모델의 1차 실험(사진 30장) 결과가 있어야 한다. 주차별 계획은 [공통규칙/일정.md](공통규칙/일정.md).

## 꼭 지킬 것 다섯 가지

1. 실험 조건은 `공통규칙/settings.py`의 값으로만. 바꾸려면 두 팀 합의 → 버전 올림 → 문서도 수정.
2. 공격 사진은 원본 모델로 **한 번만** 만들고 고정한다. 평가용 사진으로 공격 설정을 조정하지 않는다.
3. 결과 CSV는 코드가 쓴 그대로 올린다. 손으로 고치지 않는다.
4. 사진은 무손실 PNG로만 저장한다. JPEG는 노이즈를 지운다.
5. 공격 사진은 우리 기기와 우리가 띄운 모델에만 넣는다.
