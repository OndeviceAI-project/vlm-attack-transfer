# 진행 단계 — 권장 순서 (규칙이 아니라 참고)

```
image_list.csv → [1] 사진 준비 → clean, noise
                → [2] 공격 사진 (원본 모델로 한 번) → adv
                → [3] 경우마다 모델을 올려 같은 PNG를 넣는다 → results/*.csv
                → [4] 두 팀 CSV를 합쳐 그림 (공동 담당)
```

**1. 사진 준비.** `image_list.csv`의 사진을 COCO에서 받아 모델 입력 크기 정사각형으로 → `data/clean/`. 노이즈 대조군은 clean을 `int16`으로 읽고 `numpy.random.default_rng([2026, coco_id]).choice([-1, 1], size=arr.shape)`로 부호를 뽑아 `arr + 8*sign`을 0~255로 잘라 → `data/noise/`. 그다음 `ref` 모델에 clean 43장을 넣어 답이 512에 닿는 사진을 골라내고, 통과한 것 중 앞 30장을 `eval_v1.txt`로 확정한다(A팀이 먼저 하고, B팀 쪽에서 추가로 걸러지는 사진은 B 결과에서만 빠진다).

**2. 공격 사진.** `이미지생성/README.md`. 30장이 끝나면 PNG·로그·해시를 한 PR로 올리고 그 뒤 손대지 않는다.

**3. 전이 실험.** 경우 목록은 `settings.PRESETS["phase1"]`(`ref` 포함). 경우마다 모델을 올리고 → rtn이면 `apply_rtn`, bnb면 다른 부품을 `llm_int8_skip_modules`에 → `census`로 확인 → 사진 30 × 입력 3을 돌려 답마다 CSV 한 줄. 끝나면 `.json`에 설정 버전·환경·census를 남긴다. 시간이 남으면 `phase1-extra`.

**4. 분석.** 공동 담당이 두 팀 CSV로 `결과형식.md` 2절의 지표와 그림 2·3·4를 만든다.
