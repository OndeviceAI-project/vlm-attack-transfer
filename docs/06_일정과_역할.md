## 3. 역할

팀 안에서 사람 이름은 회의에서 정해 아래 빈칸을 채운다. 역할은 사람이 아니라 **책임**으로 적는다.

| 역할 | 책임 | A팀 | B팀 |
|---|---|---|---|
| 실행 담당 | 0~3단계를 돌리고 결과 PR을 올린다. 실험기록 이슈 작성 | | |
| 검수 담당 | **상대 팀**의 결과 PR을 체크리스트로 승인한다. census·설정 버전·해시 확인 | | |
| 분석·그림 | 4단계. 두 팀 결과를 합쳐 summary와 그림 2~4 (공동 1명) | | |
| 발표·문서 | 7분 자료, 예상 질문, 최종 보고서 뼈대 (공동 1명) | | |
| 저장소 관리 | 브랜치·PR 규칙 유지, settings 버전 관리, 이슈 정리 (공동 1명) | | |

5명이면 실행 담당이 팀마다 1명, 나머지 3명이 검수를 교차로 맡으면서 분석·발표·저장소를 하나씩 든다.

## 4. 회의

- 주 1회 30분(일요일 저녁 제안) + 10/16(금) go/no-go 회의.
- 회의의 첫 안건은 항상 **"이번 주에 나온 숫자"**다. 숫자가 없는 주가 두 번 이어지면 범위를 줄인다(docs/08).
- 결정 사항은 이슈에 한 줄씩 남긴다. 회의록 파일은 따로 두지 않는다.
