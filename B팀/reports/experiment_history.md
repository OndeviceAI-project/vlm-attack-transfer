# 실험 진행 기록

이 문서는 진행 과정의 요약이다. 예비 실험 상세 자료 16개와 실행 당시 코드·설정 사본 20개는 업로드에서 제외하고 원격 서버에 별도 보관했다.

1. dev 5장으로 Qwen 전처리·EOS·공격·8조건 측정 코드를 확인했다. 당시 예비 실험의 성공 기준 해석은 본실험 판정에 사용하지 않았다.
2. dev 2장에서 500회·5,000토큰·20회 간격 25후보·±20% 재검사 방식을 시험했다. 이 단계는 이후 확정한 결정적 GPU 설정을 적용하기 전이었다.
3. 반복 결과가 달라져 고정 PNG 답변과 이미지 최적화를 분리해 조사했다. 같은 PNG 답변은 반복 일치했지만 기본 GPU 계산으로 생성한 PNG는 달랐다. 결정적 설정의 20회 진단에서는 두 실행의 기울기·이미지·출력이 같았다. 특정 커널 하나를 원인으로 확정하지는 않았다.
4. dev 1장을 독립 프로세스에서 각각 500회 최적화해 비교했다. 25후보 PNG·답변 토큰 ID·채택 이미지가 일치했다. 해당 환경·해당 1장에서의 확인이며 모든 사진의 재생성을 검증한 것은 아니다.
5. **확장 설정 본실험**: eval 30장을 500회 고정·5,000토큰·25후보·±20% 재검사로 생성하고 720행 측정을 완료했다. 채택·재검사·후속 ref 토큰 수는 30장 모두 같았다. 결과는 `qwen2vl_vision_extended_v1_r01`로 포함한다.
6. **공통 설정 본실험**: 512토큰·300회 예산·조기 종료로 별도 PNG 30장과 공통 8열 형식의 720행 CSV를 만들었다. 2026-10-15 15:51~16:48(KST), 약 57분. 결과는 `qwen2vl_vision_common_v1_r01`로 포함한다. 공통 예시와 다른 구현 사항은 B팀 README에 설명했다.

두 본실험은 사진 ID가 같지만 공격 PNG 세트와 조건이 다르다. 이후 다른 부품의 양자화 측정에는 고정 PNG를 재사용하고 새 실험 이름을 사용한다. 성공률·전이율 분석은 수행하지 않았다.
