# A팀 — SmolVLM-256M-Instruct

## 목표

10/30까지 **SmolVLM-256M에서 "비트 수 → 전이율" 선 하나**를 만든다. 비전 인코더를 8·6·5·4·3비트(+ bitsandbytes 8·4)로 양자화한 모델에, 원본 모델로 만든 공격 사진 30장이 몇 % 살아남는지. 예비 실험(3장)에서는 8비트 유지, 4비트 무력화였다. 30장에서도 그런지, 문턱이 어디인지가 이번 결과다.

돌릴 경우는 여덟 개(`settings.PRESETS["phase1"]`): `ref`, `rtn-V-8`, `rtn-V-6`, `rtn-V-5`, `rtn-V-4`, `rtn-V-3`, `bnb-V-8`, `bnb-V-4`. 시간이 남으면 `phase1-extra`.

## 할 일 순서

1. **환경.** 예비 실험 기계(5060 Ti, torch 2.11 / transformers 5.19 / bitsandbytes 0.50)를 그대로 쓰면 된다. 노트북 맨 위에 `sys.path.insert(0, "<저장소>/공통규칙")` 후 `import settings, quant_rtn`.
2. **사진.** `공통규칙/image_list.csv`의 48장을 받아 512×512로 → `data/clean/`, 노이즈 대조군 → `data/noise/`(`공통규칙/진행단계.md` 1단계). 프로세서는 `do_image_splitting=False, size={"longest_edge": 512}`.
3. **유효성 검사 → `eval_v1.txt` (10/14).** `ref`에 eval 후보 43장의 clean을 넣어 512에 닿는 사진을 빼고, 통과한 것 중 앞 30장을 `공통규칙/eval_v1.txt`로 커밋한다.
4. **공격 코드 손보기.** `이미지생성/README.md`의 "손볼 것" 네 가지. 끝나면 PR — B팀이 그 뒤의 파일을 복사한다.
5. **0단계 확인 세 가지**: 전처리 일치 차이 0, census(V 72 / C 1 / L 210 / H 1), 같은 사진 두 번 → 같은 답.
6. **공격 사진 30장.** `eval_v1`의 30장으로 생성(사진당 5분 상한) → 저장본 확인 → `SHA256SUMS` → PR. 이후 `data/adv/`는 손대지 않는다.
7. **전이 실험 phase1.** `참고_예비실험/2_…ipynb`를 출발점으로: 경우마다 모델 올리기 → `rtn-*`은 `quant_rtn.apply_rtn(model, PARTS, "V", bits)`, `bnb-*`는 기존 `load_case` 방식 → `census` 확인 → 90개를 돌려 답마다 CSV 한 줄(`settings.GEN_KWARGS` 그대로) → json. 끝나면 `phase1-extra`.
8. **올리기.** 브랜치 `a/<내용>` → PR → B팀 1명이 확인 → 병합.

## 미리 확인해 둔 것

- 프로세서에 size를 안 주면 기본값 2048이 512 사진을 키웠다 줄여 픽셀이 바뀐다(평균 1.3/255, 최대 24/255). `size={"longest_edge": 512}`로 두면 0.
- 이미지 토큰 64, 입력 76토큰. 종료 토큰 49279. `tie_word_embeddings` False.
- `quant_rtn.apply_rtn`으로 V를 4비트로 하면 가중치 변화 9.38% (예비 실험 nf4 9.42%와 같은 크기).
